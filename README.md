# Home Network Security Checklist

## Project Overview

This project reviews the security settings of my home Wi-Fi network and connected devices. It aims to identify security weaknesses and improve network safety.

## Objectives

* Create an inventory of personal devices.
* Review home router security settings.
* Check device updates and backups.
* Prepare before-and-after security checklists.
* Collect evidence of security improvements.

## Devices Inventory

The inventory may include:

* Laptop or desktop
* Smartphone
* Smart TV (if available)
* Tablet (if available)
* Other personal devices connected to Wi-Fi

## Router Security Review

The following settings will be checked:

* Wi-Fi password strength
* WPA2 or WPA3 encryption
* Router administrator password
* WPS status
* Router firmware updates
* Guest network settings

## Updates and Backups

* Check operating system updates.
* Check antivirus/security updates.
* Review important data backups.
* Install available updates from trusted sources.

## Before and After Checklist

The checklist will record the security settings before and after making improvements.

## Evidence

Screenshots of relevant security settings and update status will be included. Personal information, passwords, public IP addresses, and Wi-Fi credentials will be hidden.

## Conclusion

This project helps improve home network security by reviewing router settings, updating devices, and following safe backup practices.

**Disclaimer:** This project reviews my own home network and devices. No unauthorised network access or testing is performed.
